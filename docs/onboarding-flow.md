# VozConta onboarding flow

## Goal

Guide a new business owner through setup with a smooth, voice-first onboarding experience.

## Flow

1. Splash screen
   - brand logo
   - tagline: "Accounting made simple with your voice"

2. Welcome / sign-up
   - create account
   - sign in
   - continue as guest (optional)

3. Business profile
   - retail store
   - auto workshop
   - currency exchange
   - services / other

4. Setup preferences
   - choose primary currency
   - set locale
   - enable voice capture
   - select notification preferences

5. Permissions
   - microphone access
   - notifications
   - optional device integrations

6. Quick-start overview
   - add first client
   - record first transaction
   - review balance summary

7. Dashboard preview
   - cards for total receivables
   - due today
   - recent activity
   - voice shortcut button

## Example voice commands

- "Add new client: Juan Perez"
- "Record payment from Juan 1000"
- "Show my receivables today"
- "What is the balance of store account 04?"
- "Create invoice for Maria for 2500"

## Desired user experience

- short steps
- minimal typing
- clear business context
- friendly onboarding with progress indicators
